# JS Testing Jasmine

Projeto de testes unitários desenvolvido em **JavaScript** utilizando o framework **Jasmine**, com foco na validação de regras de negócio e na aplicação de boas práticas de testes automatizados.

##  Sobre o Projeto

Este projeto foi criado com o objetivo de demonstrar a implementação de testes unitários em JavaScript utilizando o Jasmine Framework.

Os cenários implementados contemplam:

- Operações matemáticas em calculadora.
- Validação de maioridade.
- Estruturação de testes automatizados.
- Organização entre código-fonte e testes.

##  Tecnologias Utilizadas

- JavaScript
- Jasmine Framework
- HTML
- Git
- GitHub

##  Estrutura do Projeto

```text
js-testing-jasmine/
│
├── src/
│   ├── calculadora.js
│   └── maioridade.js
│
├── spec/
│   ├── calculadora.spec.js
│   └── maioridade.spec.js
│
├── SpecRunner.html
└── README.md
```

## Casos de Teste Implementados

### Calculadora

- Soma de valores.
- Subtração de valores.
- Multiplicação de valores.
- Divisão de valores.

### Validação de Maioridade

- Retorno "Maior Idade" para pessoas com 18 anos ou mais.
- Retorno "Menor Idade" para pessoas com menos de 18 anos.

##  Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/souzamtech/js-testing-jasmine.git
```

2. Acesse a pasta do projeto:

```bash
cd js-testing-jasmine
```

3. Abra o arquivo:

```text
SpecRunner.html
```

4. O Jasmine será carregado automaticamente no navegador e exibirá os resultados dos testes.

## 📷 Exemplo de Resultado

```text
4 specs, 0 failures
Finished in 0.005 seconds
```
